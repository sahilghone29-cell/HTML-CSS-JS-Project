## Schema Explanation (`schema/userSchema.js`)
The user schema defines the structural constraints and validation rules for documents stored in the `users` collection:
- `name` (String, Required)
- `email` (String, Required)
- `age` (Number, Required)
- `course` (String, Required)
- `timestamps` (Automatic `createdAt` and `updatedAt` fields)

---

## Model Explanation (`model/userModel.js`)
The model module imports `userSchema` from `../schema/userSchema` and initializes the Mongoose model:
```javascript
const mongoose = require('mongoose');
const userSchema = require('../schema/userSchema');

const User = mongoose.model('User', userSchema);
module.exports = User;
```

---

## Router Explanation (`router/userRouter.js`)
The Express router isolates all business logic and database CRUD operations using Mongoose methods:
1. `POST /api/users`: Creates a new user record using `User.create()`.
2. `GET /api/users`: Retrieves all users using `User.find()`.
3. `PATCH /api/users/:id`: Updates an existing user document by ID using `User.findByIdAndUpdate(id, req.body, { new: true, runValidators: true })`.
4. `DELETE /api/users/:id`: Deletes a user document by ID using `User.findByIdAndDelete(id)`.

## API Documentation

### 1. Create User
- **HTTP Method:** `POST`
- **Endpoint:** `/api/users`
- **Status Code:** `201 Created`
- **Request Body:**
```json
{
  "name": "Rahul",
  "email": "rahul@gmail.com",
  "age": 22,
  "course": "MCA"
}
```
- **Response:**
```json
{
  "message": "User created successfully",
  "user": {
    "_id": "68abc123456789abcdef1234",
    "name": "Rahul",
    "email": "rahul@gmail.com",
    "age": 22,
    "course": "MCA",
    "createdAt": "2026-09-22T13:40:00.000Z",
    "updatedAt": "2026-09-22T13:40:00.000Z"
  }
}
```

---

### 2. Get All Users
- **HTTP Method:** `GET`
- **Endpoint:** `/api/users`
- **Status Code:** `200 OK`
- **Response:**
```json
{
  "users": [
    {
      "_id": "68abc123456789abcdef1234",
      "name": "Rahul",
      "email": "rahul@gmail.com",
      "age": 22,
      "course": "MCA"
    }
  ]
}
```

---

### 3. Update User
- **HTTP Method:** `PATCH`
- **Endpoint:** `/api/users/:id`
- **Status Code:** `200 OK`
- **Request Body:**
```json

  "age": 23,
  "course": "MCA"
}
```
- **Response:**
```json
{
  "message": "User updated successfully",
  "user": {
    "_id": "68abc123456789abcdef1234",
    "name": "Rahul",
    "email": "rahul@gmail.com",
    "age": 23,

  }
}
```

---

### 4. Delete User
- **HTTP Method:** `DELETE`
- **Endpoint:** `/api/users/:id`
- **Status Code:** `200 OK`
- **Response:**
```json
{
  "message": "User deleted successfully"
}
```

## Thunder Client Testing Guide
Use **Thunder Client** inside VS Code (or Postman) to test the APIs using base URL `http://localhost:5001`:

1. **POST** `http://localhost:5001/api/users`
   - Set Header `Content-Type: application/json`.
   - Send sample user payload.
   - Copy the generated `_id` from the response.

2. **GET** `http://localhost:5001/api/users`
   - Verify the newly created user is present in the list.

3. **PATCH** `http://localhost:5001/api/users/<USER_ID>`
   - Paste the `_id` into URL params.
   - Send JSON payload `{ "age": 23, "course": "MCA" }`.
   - Verify `age` updates to `23`.

4. **DELETE** `http://localhost:5001/api/users/<USER_ID>`
   - Send DELETE request.
   - Verify success message: `"User deleted successfully"`.
